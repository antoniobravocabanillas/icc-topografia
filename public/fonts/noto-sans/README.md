Noto Sans is bundled for server-side quotation PDFs. Source files:

- https://github.com/google/fonts/blob/main/ofl/notosans/NotoSans%5Bwdth,wght%5D.ttf
- https://github.com/google/fonts/blob/main/ofl/notosans/OFL.txt

The original font is embedded without outline conversion or subsetting. Its SIL Open Font License is included in OFL.txt. Quotation rendering uses local assets only.
